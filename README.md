# CodSoft C++ Programming Virtual Internship

This repository contains the projects completed as part of my **C++ Programming Virtual Internship at CodSoft**.

The internship focuses on applying C++ programming concepts through practical, project-based tasks and developing problem-solving and application development skills.

## Internship Details

- **Organization:** CodSoft
- **Domain:** C++ Programming
- **Internship Type:** Virtual Internship
- **Duration:** 5 September 2026 – 5 October 2026
- **GitHub Repository:** Maintained as a dedicated repository for the internship

## Completed Tasks

### Task 1 – Random Number Guessing Game

A graphical number guessing game developed using C++ and the Windows API.

The application:

- Generates a random number between 1 and 100
- Accepts guesses from the user
- Provides "Too High" or "Too Low" feedback
- Tracks the number of attempts
- Displays the result when the correct number is guessed
- Allows the user to start a new game

**Technologies:** C++, Win32 API

[View Task 1](./Task-1-Random-Number-Guessing-Game/)

---

### Task 2 – Tic-Tac-Toe Game

A two-player Tic-Tac-Toe game developed in C++ with both console and native Windows GUI interfaces.

The application includes:

- Two-player gameplay
- 3×3 game board
- X and O players
- Win detection
- Draw detection
- Invalid move handling
- Play Again functionality
- Console mode
- Win32 GUI mode

**Technologies:** C++, Win32 API

[View Task 2](./Task-2-Tic-Tac-Toe/)

---

### Task 3 – To-Do List Manager

A graphical To-Do List Manager developed using C++ and the Windows API.

The application allows users to:

- Add tasks
- View tasks
- Mark tasks as completed
- Remove tasks
- View pending and completed task counts
- Manage tasks through a graphical interface

**Technologies:** C++, Win32 API, Windows Common Controls

[View Task 3](./Task-3-To-Do-List/)
